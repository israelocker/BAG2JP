# BAG2JP

Bust A Move 2 - Dance Tengoku Mix (SLPM-86219) recompiled to Windows with PSXRecomp, plus mods.
See NOTES.md for the full log (builds, reverse-engineering findings, mod packages).

- `mods-src/` - source of every mod package (C plugins, manifests, build tools)
- `patches/` - local patches to the PSXRecomp runtime
- `ghidra-scripts/` - helper scripts for Ghidra
- Not in git: `assets/`, `releases/`, `_work/`, Ghidra project, generated payloads/media.
